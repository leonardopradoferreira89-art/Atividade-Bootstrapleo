Conhecendo o Bootstrap

Documentação técnica didática exigida na atividade prática de Front-End

O que é o Bootstrap?

O Bootstrap é o framework front-end open-source mais popular do mundo, criado originalmente pela equipe do Twitter. Ele disponibiliza uma coleção completa de estilos CSS e utilitários em JavaScript prontos para uso.

Com ele, o desenvolvedor cria interfaces elegantes utilizando apenas classes predefinidas diretamente no código HTML sem precisar escrever CSS do zero.

Para que serve?

O framework acelera o desenvolvimento web e resolve os seguintes desafios:

  • Compatibilidade entre navegadores: Visual padronizado em todos os navegadores modernos.
  • Agilidade e Produtividade: Oferece botões, modais, carrosséis, menus e tabelas prontos.
  • Mobile-First Nativo: Permite desenhar sites adaptáveis primeiro para celulares e depois para telas maiores.

Como Funciona o Sistema de Grid (Grid System)

Layout flexível baseado em um contêiner virtual dividido em 12 colunas

A estrutura de Grid do Bootstrap exige uma hierarquia composta por três classes essenciais:

1. .container

Estabelece os limites de largura da página e centraliza o conteúdo na tela do dispositivo.

2. .row

Representa a linha horizontal responsável por agrupar as colunas utilizando Flexbox.

3. .col-*

Representa as colunas individuais que definem quantas partes das 12 colunas o elemento usará.
