Conhecendo o Bootstrap

Guia completo sobre a ferramenta e os conceitos aplicados neste projeto.

O que é o Bootstrap?

O Bootstrap é o framework front-end mais popular do mundo para desenvolvimento web ágil, responsivo e baseado em componentes reutilizáveis.

Para que serve?

Ele resolve problemas complexos de compatibilidade entre navegadores e acelera o design de interfaces através de classes CSS prontas e padronizadas, dispensando a necessidade de escrever todo o CSS do zero.

Sistema de Grid

O sistema de grid do Bootstrap utiliza uma estrutura de 12 colunas flexíveis baseada em flexbox.

  • .container: Centraliza e limita a largura do conteúdo na tela.
  • .row: Cria uma linha horizontal para agrupar colunas e alinhar espaçamentos.
  • .col, .col-md-*, .col-lg-*: Definem a largura proporcional do elemento de acordo com o tamanho do dispositivo (celular, tablet, monitor).

Design Responsivo

O design responsivo permite que a aplicação adapte sua estrutura visual perfeitamente para qualquer tipo de tela:

Celulares
1 coluna (col-12)
Tablets
2 colunas (col-md-6)
Notebooks
3 colunas (col-lg-4)
Monitores
Layout fluido

5 Componentes Principais Utilizados no Projeto

1. Navbar

Barra de navegação superior responsiva com colapso automático em dispositivos móveis.

2. Cards

Utilizados para estruturar de forma organizada os pratos do cardápio e os diferenciais do restaurante.

3. Botões (Btn)

Elementos interativos estilizados com cores padronizadas (`btn-wine`, `btn-outline-light`).

4. Alertas (Alert)

Caixas de aviso informativas com destaque visual para horários e status.

5. Formulários & Modais

Campos de entrada e janelas flutuantes interativas para reservas e carrinho de pedidos.
